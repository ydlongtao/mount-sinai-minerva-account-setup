步骤与依赖关系

Step 1. 结果校正与 H5AD 结构验证 第一步

目标：确认所有结果文件可读、空间坐标完整、counts layer 和 gene names 正确，并修正报告统计错误。

输入：results/batch/ 下的 10 个样本 H5AD、QC JSON/CSV、整合 H5AD。

检查：obs/var 唯一性、obsm["spatial"]、counts layer、零 counts、异常 counts、空间坐标范围、样本和分组标签。

输出：results/validation/、结构检查表、异常样本清单、修正后的本地 HTML 报告。

资源：CPU，express，1–2 cores，8–16 GB；不需要 GPU。

验收：10/10 样本结构检查通过；异常项均记录，不静默修复。

Step 2. 样本级 QC 与组织覆盖评估 依赖 Step 1

目标：建立 16um、8um、Cellpose 三套独立 QC，不用一个阈值强行适配所有样本。

  • 16um：total counts、detected genes、组织覆盖、线粒体比例、零 counts 比例。
  • 8um：只对有可靠 barcode mapping 的样本进入 mapped 分析。
  • Cell-level：按样本内分布过滤低质量细胞和异常大细胞。

重点样本：R4、R6、R9、TD006859-B408、TD006859-B573。

输出：样本 QC 表、阈值记录、QC 图、是否进入后续统计的样本清单。

资源：CPU，express；大型 H5 读取可申请 4 cores、24 GB。

Step 3. 裁剪坐标与 H&E Cellpose 质量复核 依赖 Step 2

目标：确认当前固定裁剪区域确实覆盖组织，并验证 Cellpose label、H&E 图像和表达 bin 的空间重叠。

重点：对 R4、R6、R9、B408、B573 生成全组织预览、多裁剪区域叠加图和 Cellpose 边界图。

必要时：把单一的 1,000 × 1,000 um 裁剪改为全组织或多个 ROI；保留原 v1 结果，不覆盖。

输出：results/segmentation_review/、H&E overlay、label overlay、细胞覆盖率表。

资源：GPU 优先使用 H100/A100；Cellpose 必须记录 CUDA 是否真正启用。GPU 不可用时使用 CPU 备用队列。

Step 4. 正式 Cellpose/bin2cell 细胞矩阵 依赖 Step 3

目标：获得适合细胞级分析的 raw-count cell-by-gene 矩阵。

策略：先处理通过 ROI/组织覆盖检查的样本；B408、B573 暂列为描述性结果，不进入组间检验。

输出：每样本 cell-level H5AD、细胞边界 GeoJSON、细胞 QC、label 与表达叠加图。

资源：Cellpose/图像推理使用 GPU array；bin2cell 及矩阵汇总使用 CPU array。临时文件放在 /sc/arion/scratch/huangl21/sp_project/。

Step 5. 细胞类型与状态注释 依赖 Step 4

目标：从 marker score 升级到可审计的细胞类型注释。

候选类型：luminal/tumor epithelial、basal epithelial、neuroendocrine-like、CAF、smooth muscle、endothelial、T cell、B/plasma、myeloid/macrophage、cycling、low-quality/ambiguous。

判定标准：多个 marker 一致、QC 正常、空间位置合理、至少在多个样本可复现。

输出：cluster marker 表、注释表、UMAP、空间注释图、每样本细胞组成表。

资源：CPU 为主；GPU 可用于 PCA/neighbors，但不是必要条件。

Step 6. 多分辨率整合与稳定性评估 依赖 Step 5

目标：解决当前 16um 产生 424 个 cluster 的过度分群问题。

分辨率：0.02, 0.05, 0.1, 0.2, 0.4；同时评估 cluster size、marker、sample mixing、UMAP 和空间投影。

统计原则：cell-level 和 16um 分析分开建模；整合只用于表达空间和注释，不替代样本级统计。

输出：分辨率比较报告、稳定 cluster 清单、推荐 resolution、批次效应诊断。

资源：CPU premium，8 cores，24–48 GB；GPU 只在验证 RAPIDS/Dask 兼容后启用。

Step 7. 空间域与空间变异基因 依赖 Step 5–6

目标：识别肿瘤上皮、基质、免疫、血管及其边界等空间组织区域。

方法：Squidpy neighborhood graph、Moran’s I、spatially variable genes、domain clustering、marker score spatial overlay。

输出：空间域图、空间变异基因表、肿瘤-基质边界图、每个域的 marker 和组成。

资源：CPU 为主；大规模 16um graph 可使用 GPU RAPIDS，但必须记录 GPU 实际使用情况。

Step 8. 空间邻域、共定位与空间通讯 最后执行

目标：在细胞类型和空间域可信后，分析肿瘤-CAF、肿瘤-免疫、肿瘤-血管等空间关系。

分析：neighborhood enrichment、co-occurrence、距离约束 ligand-receptor、样本内 permutation、样本级汇总。

限制：不把每个 cell/bin 当作独立重复；B408/B573 只做描述性展示。Spatial transition tensor 暂缓，待细胞注释和样本覆盖充分后再评估。

输出：邻域富集矩阵、共定位曲线、候选通讯网络、通路级汇总和多重检验结果。

最终验收标准

  • 所有进入正式统计的样本有结构检查、QC 和空间覆盖记录。
  • Cellpose label 与 H&E/表达空间一致，异常样本有明确处理记录。
  • 每个细胞类型有 marker、QC、空间分布和样本复现证据。
  • 组间统计以样本为重复单位，并报告样本数量和有效细胞数。
  • 空间通讯结果经过距离约束、背景/置换校正和多重检验。
  • 每个 GPU 任务记录节点、CUDA_VISIBLE_DEVICES、PyTorch CUDA 状态和是否发生 CPU fallback。

本计划基于当前 v1 批量结果制定。v1 原始结果保留不覆盖；后续修改应另存为 v2 或更高版本。
